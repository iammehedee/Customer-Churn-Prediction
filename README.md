# Customer Churn Prediction
Machine Learning project to predict Telco customer churn.
Customer churn means customers leaving the telecom service. This model helps businesses identify customers at risk of leaving and take retention actions.

## 📊 Dataset
Telco Customer Churn Dataset (Kaggle)
- `WA_Fn-UseC_-Telco-Customer-Churn.csv`
- 7043 customer records
- Features: gender, age, monthly charges, contract type, internet service, payment method etc.
- Target variable: `Churn` (Yes / No)

## 🧪 Project Workflow
1. Data Cleaning & Exploratory Data Analysis (EDA)
2. Feature Engineering & Encoding
3. Train/Test Split
4. Model Building:
   - Logistic Regression
   - Random Forest
   - XGBoost
5. Model Evaluation: Accuracy, Precision, Recall, F1-Score, Confusion Matrix
6. Conclusion & Business Recommendations
